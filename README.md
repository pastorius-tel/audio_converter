# 音声ファイル変換ツール (Audio Preset Converter)

タカコム留守番・ナカヨ・岩崎通信機など、業務用電話機・留守番電話システム向けに、
一般的な音声ファイルを ffmpeg 経由で指定フォーマットへ一括変換する
Windows デスクトップ GUI アプリです
(Rust + [egui](https://github.com/emilk/egui)/[eframe](https://github.com/emilk/egui/tree/main/crates/eframe))。

## 機能

- 単一/複数ファイルの選択(ボタン、またはドラッグ&ドロップ)
- 対象機器ごとに用意された5プリセットから選んで一括変換
- 出力先フォルダ指定(未指定時は入力ファイルと同じ場所)
- 出力ファイル名に変換日時を自動付与、同名衝突時は自動的に連番を付与
- 変換進捗バー / ログ表示
- 録音時間に上限があるプリセットでは、超過ファイル・長さ不明ファイルを
  自動スキップし、完了後にまとめて警告ダイアログを表示

## 対応プリセット

| メーカー | プリセット | コーデック | サンプリング | ビット深度 | チャンネル | 備考 |
|---|---|---|---|---|---|---|
| タカコム留守番 | μ-law 8kHz 8bit モノラル | pcm_mulaw | 8000 Hz | 8bit | 1 | |
| タカコム留守番 | PCM 44.1kHz 16bit モノラル | pcm_s16le | 44100 Hz | 16bit | 1 | |
| タカコム留守番 | PCM 44.1kHz 16bit ステレオ | pcm_s16le | 44100 Hz | 16bit | 2 | |
| ナカヨ | AAC (ADTS) 8kHz 24kbps モノラル (LC) | aac (LC profile) | 8000 Hz | - | 1 | 拡張子 `.aac`、ADTSコンテナ、CRC保護なし |
| 岩崎通信機 | PCM 8kHz 16bit モノラル (録音2分以内) | pcm_s16le | 8000 Hz | 16bit | 1 | **録音時間が120秒を超える、または長さを取得できないファイルは自動スキップ** |

## 必要なもの

- Rust toolchain 1.76 以上
  (egui/eframe 0.29 系の要求バージョン。egui は破壊的変更が頻繁に入るクレートのため、
  `Cargo.toml` のコメントに記載の理由を確認してからバージョンを変更してください)
- `ffmpeg.exe`
  - PATH に通すか、アプリと同じフォルダに配置
  - 配置した場合はアプリ内の `ffmpeg:` 欄で参照ボタンから指定するか、
    自動検出(同じフォルダの `ffmpeg.exe` を優先的に探します)に任せてください

## ビルド

```sh
cargo build --release
```

成果物: `target/release/audio_converter.exe`

Windows 以外の OS では GUI 依存クレート(`eframe`)のビルドに追加の
システムライブラリが必要になる場合がありますが、本アプリは
Windows 専用設計(Windows のフォントパス、コンソール非表示化 等)です。

配布する場合は `ffmpeg.exe` を同梱して zip にまとめると運用が楽です。

### 単体テスト

GUI に依存しない純粋ロジック(ffmpeg のDuration行パース、パス比較、
出力ファイル名の重複回避など)は `src/logic.rs` に分離してあり、
GUI 依存クレートなしで検証できます。

```sh
cargo test
```

## アイコンを埋め込む

プロジェクトルート(`Cargo.toml` と同じ階層)に **`icon.ico`** を置いて
ビルドすれば、そのまま `audio_converter.exe` のアイコンとして
埋め込まれます(`icon.ico` は本リポジトリには含まれていません)。

### 仕様

- ファイル名: `icon.ico` (固定)
- 形式: Windows ICO 形式(`.ico`)
- 推奨解像度(マルチサイズ ICO に同梱): 16×16 / 32×32 / 48×48 / **256×256**
- 色深度: 32bit RGBA(アルファチャンネルあり)

### PNG → ICO 変換例(ImageMagick)

```sh
magick convert icon-256.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico
```

### 動作

- `icon.ico` が無ければ警告だけ出してアイコンなしでビルド続行します
- `icon.ico` を差し替えると `cargo build` 時に自動的に再ビルドされます
- クロスコンパイル時も正しく動作するよう、ターゲットOS判定は
  `CARGO_CFG_TARGET_OS` 環境変数を見て行っています

## プリセットの追加/変更方法

`src/main.rs` の `Preset` enum と、対応する `group()` / `label()` /
`extension()` / `ffmpeg_args()` / `max_duration_secs()` を編集してください。
録音時間などの制約は `max_duration_secs()` にデータとして追加するだけで、
変換ループ側のコードを変更する必要はありません。

```rust
enum Preset {
    // ...
    YourNewPreset,
}

// group() / label() / extension() / ffmpeg_args() にそれぞれ分岐を追加
// 時間制限が必要なら max_duration_secs() に Some(秒数) を追加
```
